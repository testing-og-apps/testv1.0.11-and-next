How to install

Annua is installed straight from the APK file.

  1. Tap Download for Android and open the downloaded Annua.apk.
  2. If Android asks, allow installing from this source (your browser or file manager).
  3. Open Annua and allow notifications, exact alarms and unrestricted battery so reminders arrive on time.

Updating? Install the new APK over the old one and your data stays. Or use Settings → App update inside the app.
